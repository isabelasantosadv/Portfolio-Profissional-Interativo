# Interactive Professional Portfolio

**An adaptive, multilingual professional portfolio template for presenting one professional trajectory to different audiences, roles and contexts.**

[Live Demo](https://isabelasantosadv.github.io/Portfolio-Profissional-Interativo/)

> This project started as my own interactive professional portfolio and is being developed as a reusable template for professionals who want something more expressive than a traditional resume.

## Why this project?

A conventional CV is linear. Professional work is not.

The same person may need to communicate different parts of their experience to a recruiter, client, board, academic institution, founder or business partner.

This portfolio uses a different approach:

**one professional identity + structured evidence + contextual presentation.**

It does not create fictional personas or different versions of the professional. It reorganizes the same verified experience according to the visitor's intent.

## Current features

- Responsive static website
- GitHub Pages compatible
- Portuguese, English and Spanish interfaces
- Audience-oriented profile perspectives
- Business Counsel positioning
- Technology, regulation, governance, advisory and research perspectives
- Evidence-oriented professional profile
- Career timeline
- Local question-and-answer layer
- Browser speech output through the Web Speech API
- No framework or build step required

## Professional perspectives

- **Technology Lawyer** — digital products, technology contracts, AI, privacy and legal operations
- **Financial Regulation** — financial services, Open Finance, payments and regulated businesses
- **Governance & Compliance** — governance, risk, compliance and AI governance
