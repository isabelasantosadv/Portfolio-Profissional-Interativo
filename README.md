# Portfolio Profissional — Isabela Schattgen

## V2 — Adaptive Professional Portfolio

Este projeto evolui o currículo conversacional original para uma representação profissional adaptativa.

### Posicionamento central
**Business & Technology Lawyer | Regulation, Contracts, Governance & AI**

A experiência é organizada em seis perspectivas:
- Business Counsel
- Technology Lawyer
- Financial Regulation
- Governance & Compliance
- Board Advisory
- AI & Research

### Arquitetura da V2
A primeira etapa permanece 100% estática e compatível com GitHub Pages. Ela já implementa:
- navegação por intenção do visitante;
- reorganização contextual do perfil;
- camada de evidências;
- timeline da carreira;
- chat local baseado em conteúdo estruturado;
- leitura por voz via Web Speech API;
- design responsivo.

### Próximas camadas
1. Extrair conteúdo para uma base estruturada (/data).
2. Conectar um motor de IA/RAG com respostas limitadas às evidências autorizadas.
3. Adicionar avatar visual e voz.
4. Criar modos específicos para recrutador, cliente, board e pesquisa.
5. Gerar CVs direcionados a oportunidades a partir de uma descrição de vaga.

### Princípio
O portfolio deve adaptar **a apresentação da mesma trajetória**, e não criar personas ou experiências diferentes.
