# Security Policy

## Scope

This repository publishes a static professional portfolio through GitHub Pages. It does not intentionally collect passwords, payment data, authentication credentials, or other sensitive information.

## Content integrity

The public website is generated from repository-controlled files. Visitor input is not written back to the repository, stored as profile content, or executed as code. The interactive Q&A is local and rule-based; it does not execute arbitrary visitor prompts.

Professional claims should be changed only through reviewed repository changes. Do not place secrets, private client information, unpublished case details, credentials, API keys, tokens, or sensitive personal data in this repository.

## Reporting a vulnerability

If you discover a security issue that could affect the integrity, availability, privacy, or confidentiality of the project, please report it privately through GitHub's repository security reporting mechanism when available, rather than publishing exploit details in an issue.

## Deployment note

GitHub Pages supports HTTPS. The site should be configured with **Enforce HTTPS** in repository Settings → Pages. GitHub also recommends not using Pages for sensitive transactions or storing sensitive data in the repository.
