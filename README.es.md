# Portafolio Profesional Interactivo

**Una plantilla de portafolio profesional adaptativa y multilingüe para presentar una trayectoria profesional a diferentes públicos, roles y contextos.**

[Ver demo](https://isabelasantosadv.github.io/Portfolio-Profissional-Interativo/)

> Este proyecto nació como mi propio portafolio profesional interactivo y está siendo desarrollado como una plantilla reutilizable para profesionales que quieren ir más allá del currículum tradicional.

## ¿Por qué este proyecto?

Un CV convencional es lineal. El trabajo profesional no lo es.

Una misma persona puede necesitar presentar diferentes partes de su experiencia a un reclutador, cliente, consejo, universidad, fundador o socio de negocios.

Este portafolio utiliza otra lógica:

**una identidad profesional + evidencia estructurada + presentación contextual.**

El sistema no crea personajes ficticios ni versiones diferentes del profesional. Reorganiza la misma experiencia según la intención de quien visita.

## Funcionalidades actuales

- Sitio web responsive
- Compatible con GitHub Pages
- Interfaz en portugués, inglés y español
- Perspectivas orientadas al público
- Posicionamiento como Business Counsel
- Perspectivas de tecnología, regulación, gobierno corporativo, advisory e investigación
- Perfil basado en evidencias
- Línea de trayectoria profesional
- Capa local de preguntas y respuestas
- Lectura mediante Web Speech API
- Sin framework ni proceso de build obligatorio

## Perspectivas profesionales

- **Business Counsel** — contratos, deals, negociación, alianzas y asesoramiento empresarial
- **Technology Lawyer** — productos digitales, contratos tecnológicos, IA, privacidad y operaciones jurídicas
- **Financial Regulation** — servicios financieros, Open Finance, pagos y negocios regulados
- **Governance & Compliance** — gobierno corporativo, riesgos, compliance y gobernanza de IA
- **Board Advisory** — apoyo estratégico para decisiones en la intersección entre negocio, tecnología y regulación
- **AI & Research** — inteligencia artificial, gobernanza tecnológica, investigación y docencia

## Úsalo como plantilla

Haz un fork y sustituye los datos profesionales, textos e identidad visual por los tuyos. La arquitectura estática facilita inspección, personalización y publicación en GitHub Pages.

## Tecnología

HTML · CSS · JavaScript puro · Web Speech API · GitHub Pages
