# Portfólio Profissional Interativo

**Um template de portfólio profissional adaptativo e multilíngue para apresentar uma trajetória profissional a diferentes públicos, funções e contextos.**

[Ver demonstração](https://isabelasantosadv.github.io/Portfolio-Profissional-Interativo/)

> Este projeto nasceu como meu próprio portfólio profissional interativo e está sendo desenvolvido como um template reutilizável para profissionais que querem ir além do currículo tradicional.

## Por que este projeto?

Um currículo convencional é linear. O trabalho profissional não é.

A mesma pessoa pode precisar apresentar experiências diferentes para um recrutador, cliente, conselho, universidade, fundador ou parceiro de negócios.

Este portfólio parte de outra lógica:

**uma identidade profissional + evidências estruturadas + apresentação contextual.**

O sistema não cria personas fictícias nem versões diferentes do profissional. Ele reorganiza a mesma experiência de acordo com a intenção de quem visita.

## Funcionalidades atuais

- Site responsivo
- Compatível com GitHub Pages
- Interface em português, inglês e espanhol
- Perspectivas orientadas por público
- Posicionamento de Business Counsel
- Perspectivas de tecnologia, regulação, governança, advisory e pesquisa
- Perfil orientado por evidências
- Timeline profissional
- Camada local de perguntas e respostas
- Leitura pelo navegador com Web Speech API
- Sem framework ou etapa de build obrigatória

## Direções profissionais

- **Business Counsel** — contratos, deals, negociação, parcerias e aconselhamento empresarial
- **Technology Lawyer** — produtos digitais, contratos de tecnologia, IA, privacidade e operações jurídicas
- **Financial Regulation** — serviços financeiros, Open Finance, pagamentos e negócios regulados
- **Governance & Compliance** — governança, riscos, compliance e governança de IA
- **Board Advisory** — apoio estratégico a decisões na interseção entre negócio, tecnologia e regulação
- **AI & Research** — inteligência artificial, governança tecnológica, pesquisa e docência

## Use como template

Faça um fork e substitua os dados profissionais, textos e identidade visual pelos seus. A arquitetura estática facilita inspeção, customização e publicação no GitHub Pages.

## Tecnologia

HTML · CSS · JavaScript puro · Web Speech API · GitHub Pages
